# Tip Calculator Application

A straightforward Python utility designed to quickly calculate gratuity and split bills among groups. This project includes both the source directory and a standalone deployment archive.

## 📁 Repository Structure

* **`p1_tip_calci_app/`** – The main project directory containing the application source files, logic modules, and user interface scripts.
* **`p1_tip_calci_app.zip`** – A compressed archive of the project folder for quick distribution and easy local extraction.

## 🚀 Key Features

* **Gratuity Calculation:** Computes precise tip totals based on custom percentages.
* **Bill Splitting:** Divides the total bill (including tip) evenly among multiple people.
* **Clean Terminal/GUI Output:** Provides easy-to-read financial breakdowns.

## 💻 Quick Start

1. Download or clone this repository.
2. If using the zip archive, extract `p1_tip_calci_app.zip`.
3. Open your terminal or command prompt inside the project folder.
4. Execute the primary application file by running:
   ```bash
   cd p1_tip_calci_app
   python p1_tip_calci_app.py
